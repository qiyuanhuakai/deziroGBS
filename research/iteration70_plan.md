# 第70轮从端口选择推进到状态演化与误差控制

第69轮已给出可运行的 C++ PNR 重置采样器，并明确两个瓶颈：144×50 的矩阵演化主导耗时；小系统位移重置的完整总计数误差仍达约 3.6%～3.9%。后续以这些实测起点推进，不再以增加相似小例检查作为主要成果。

1. **减少重复特征分解。** 保留无探测演化的谱表示；针对探测后的低秩更新研究稳定谱更新与退化特征值处理。先在相同状态序列上分离谱更新、80次等待反演和端口选择的成本，再比较完整采样。每个被提速的原生步骤都需要独立状态核验。
2. **并行完整轨迹。** 将独立样本并行，分别量化 CPU 批次与 GPU 批次的准备、计算、内存和尾部负载不均。不能通过光子数上限丢弃第69轮发现的重尾，也不能只用空样本占比高的输入制造吞吐优势。
3. **保留非 Gaussian 条件信息。** 研究低阶多项式条件态或带误差预算的局部精确分支，重点降低总计数 TV 与极端尾部。单纯中心 Gaussian 混合有既有局部障碍；均值接近目标或阈值 TV 降低都不够。任何总计数校正都要同时验证联合模式分布和期望成本，不能只强行改写输出计数。
4. **共同物理输入与测量。** 接入核对后的九章2.0公开输入，建立相同阈值任务上的 Frugal、位移重置及 MPS 比较；之后加入九章3.0分流响应。先报告共同可计算边缘与总计数，再扩大能够判别的整体质量范围。完整保留 K4 等更准确基线。
5. **继续 MPS 构建方向。** 将 PCO/Gaussian SVD 产生的张量与第68轮 C++/CUDA 读出连接，报告构建与采样总成本、截断误差及连续噪声。优先对连接维数和实际内存作有意义的扩展。
6. **特殊图方向。** 从已完成的精确小图链走向不依赖全状态枚举的界；只有得到可用的收缩、混合或拒绝成本控制，才进入更大图的资源比较。

持续目标仍是找到在明确输入、误差和资源条件下能够超过先进经典方法及九章的方案。第69轮的 6.09～9.61 倍模型内部加速与局部质量改善不构成这一目标完成。
