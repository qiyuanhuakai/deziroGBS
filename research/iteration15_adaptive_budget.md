# 统一Fock维数与逐切口键维数的预算驱动选择

## 已有基础与本轮贡献

MPS通过限制纠缠实现压缩是成熟方法，参见[Vidal的经典模拟方案](https://arxiv.org/abs/quant-ph/0301063)和[Schollwöck的MPS综述](https://arxiv.org/abs/1008.3477)。本轮没有把自适应Schmidt截断本身作为新的理论发现；新增的是本项目局域GBS相干核心构造中的预算分配、自动重建策略与完整失败记录。

第十二轮已验证：同一层不重叠双模门的局部Fock投影可合并损失；同一从左至右的Schmidt截断扫描具有嵌套保留空间，可把条件保留权重相乘。跨层则仅使用态距离三角不等式。继续沿用该证明，不把任意连续投影当作可交换或嵌套投影。

## 选择每个切口的秩

在混合正则中心，对降序奇异值s₁,…,s_R，选择最小r≥1使

    q(r) = (Σ_{k>r} s_k²) / (Σ_k s_k²) ≤ τ,

并要求r≤χ_cap。如果没有满足者，取cap对应秩，并记录实际丢弃权重及一次cap不足。尾权重直接从谱尾累加，避免`1 − 累计大权重`吞掉微小尾部。返回实际发生的损失，而不是假定目标τ已达成。

针对一层L个光学层中的一次完整m−1切口扫描，设分给该层的态距离额度为b。取

    τ = 1 − (1 − b²)^(1/(m−1)).

若每个切口均达到τ，则联合扫描损失

    Q = 1 − ∏_j(1 − q_j) ≤ b²,

扫描引起的纯态距离至多b。数据依赖的秩选择不改变这次已实现扫描的嵌套结构。若某些切口受cap限制，仍直接计算实际Q，不伪造额度达标。

## 总预算与重建策略

给定目标ε，初始输入投影距离为δ_in。若δ_in>ε，该统一维数d无法满足当前可加预算，直接记录`input_budget_rejected`。这只排除本预算证明的达标方式，不证明真实输出误差一定超过ε。

可构造时，预留剩余额度的一半给键截断，均分到光学层：

    b = (ε − δ_in) / (2L).

执行每层局部投影后进行自适应扫描。最终以实际账本检查

    B = δ_in + Σ_l sqrt(P_l) + Σ_l sqrt(Q_l) ≤ ε.

P_l为该层局部投影的联合损失，Q_l为扫描联合损失。B是理想算术下纯核心态距离的上界，在本实现中由float64计算，未做区间认证。若某切口未满足预分额度，但最终实际B仍≤ε，可以接受；接受条件始终是最终B。

预定d梯为4、6、8、10、12，cap梯为8、16、32。若输入加局部投影已经耗尽目标，增加d；若这两项仍低于目标而总预算超标，则先增加cap。cap在跨d时不回退。到首次满足实际B为止，返回对应态；并保留所有早先尝试。

该策略是启发式，没有证明预算随d或cap单调，也不保证最小存储、最短时间或搜索空间内必然找到可行解。固定的二等分及按切口均分可能过于保守。这里所有模式共享同一个Fock维数d，只有键维数按切口变化；尚未实现各模式不同d的非均匀Fock盒。

## 资源与失败语义

每次尝试的门分支元素上限为500,000，20秒软限在门之间检查，无法中断正在进行的单个SVD；外部每任务180秒超时。遇到资源或数值失败即结束自适应搜索，保留已完成层及当前层门数，不报告部分态的完整构造预算。这不是数学不可行证明，也不意味着更大资源下不能成功。

固定d8 χ16对照共享分支元素上限和180秒外部超时，但没有自适应尝试的20秒软限。因此本轮资源受限失败不能直接用来排名两方法的理论可行性。计时仅作探索性诊断，自动重建总耗时包含丢弃尝试及每次账本写入；没有只报最后一次成功的便宜成本。

## 质量与比较边界

相同名义预算不等于相同真实误差。小系统使用未归一化的完整Gaussian态在局部Fock盒中的系数，与归一化MPS直接计算重叠；盒外原态振幅不被重新归一化。因此得到的是对原无限Fock纯态的距离，而不是两个已截断态之间的距离。

大系统目前只有构造账本，尚无实际完整测量分布。测量采样及Gaussian位移发生的有限精度误差不在B之中。自适应输出样本不能仅凭B称为已认证TV采样器。
