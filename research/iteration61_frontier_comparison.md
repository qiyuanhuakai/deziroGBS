# 第61轮：实际排序证据与前沿路线

2026-11-10重新检索并核对原始论文和官方仓库。此次实际运行的是固定Frugal原生实现；其余路线保持文献对照，不混称为本轮已复现。检索不保证穷尽所有最新工作。

| 路线 | 原始证据 | 本轮对应关系与未解决问题 |
|---|---|---|
| Frugal | [作者预印本](https://arxiv.org/abs/2511.14923)、[官方实现](https://github.com/tomdodd4598/FrugalGBS)，HEAD仍为fa8b796f2afebd4845a2e335e457735952617ef8 | 新运行144模排序面板和十模完整控制。完整16位边缘可认证，但仍不能把既定统计基准或更小边缘距离解释成整体TV保证。期刊版本已发表；本次PMC全文直接打开仍遇验证页，公式依据可读作者稿及冻结实现。 |
| Gaussian-SVD / PCO | [Liu等v2](https://arxiv.org/abs/2512.10643)，npj Quantum Inf.12,110 | 低纠缠纯Gaussian态到MPS的构造；本轮没有运行作者实现。排序在MPS中还会影响中间纠缠，但不能把本轮有限阶条件近似的排序结果直接转移到该算法。 |
| 固定损耗、Haar平均 | [Lim v1](https://arxiv.org/html/2611.01434v1)，定理2、附录A.2/D.4/F.1 | 主GBS定理要求各模式等且有界压缩、固定均匀损耗；误差对Haar线路平均。D.4明确给出有限精度与比特复杂度论证，不能将其简单描述为没有比特分析。对指定非均匀混合模型的适用性、有限常数及异常线路识别仍未解决。此文第23/35/39轮已讨论，本次是细化边界。 |
| 热损耗与高概率 | [Angrisani–Mhiri v1](https://arxiv.org/abs/2611.08444) | 固定均匀压缩、固定非零损耗和Haar高概率等条件；另有平坦性条件下的准多项式路线。与本轮某一个指定协方差的严格证书是不同量词，不能直接替代。 |
| 图上的相关GBS分布 | [Anand等v3，2026-11-06](https://arxiv.org/html/2511.16558v3)，定理1.1与引理4.1 | 图子集权重c^(2|S|)PM(S)^2可经双层图G□K₂的加权完美匹配投影获得。本文定理针对这一非负图分布，不是当前任意复Gaussian、含碰撞阈值聚合的分布。本轮新纳入构造性后续路线，尚未实现其Markov链或核验有限规模混合成本。 |
| 检测Gaussian重置、相位扩散 | [重置](https://arxiv.org/html/2610.06526)、[相位扩散](https://arxiv.org/abs/2608.31089) | 沿用第60轮适用域检查：重置主定理不自动覆盖位移噪声变体；相位扩散噪声及碰撞自由观测与当前模型不同。没有新增实现或复杂度结论。 |
| 九章4.0 | [原论文v3](https://arxiv.org/abs/2508.09092) | 报告1024压缩输入、8176模式、最高3050探测事件及25.6微秒/样本。本轮144模指定输入的16位边缘不等于该规模完整模拟，也没有与九章同质量的采样速度比较。论文指定MPS估算不构成对所有未来经典算法的通用下界。 |

本轮把“改变标签不改变理想目标”与“实际近似程序可能随顺序改变”分开验证。整体144模上界仍缺少实用保证，先进算法的渐近存在性结果与指定实例完整误差证书也仍需分开。
