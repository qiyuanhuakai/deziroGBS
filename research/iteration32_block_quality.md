# 小块完整输出、前缀顺序与上下界范围

## 有限MPS的完整四模式分布

对整体归一化且右正交的有限MPS，收缩指定连续块前方的左环境L，再连接块内张量A。块密度为ρ_nm=Σ_{a,b}(LA)_{anb}A*_{amb}，保留全部输入物理指标；不对所得ρ再次归一化，不投影到PSD锥。d=4、四模式时ρ为256×256。本轮限制连接张量至2,000万个复数元素，超限明确拒绝。

对子集S，先取ρ的部分迹，再计算q(S)=tr(ρ_S E_S)，其中E_S是Gaussian位移下平均真空效应。第29轮实Gaussian Wick矩路线给出其有限输入Fock矩阵。全部子集q确定完整二元律：

    p(C clicks, Z vacuum) = Σ_{T⊆C} (−1)^|T| q(Z∪T).

用小端位掩码保存，bit j对应块内第j个物理模式。采用完整容斥，不裁剪负项、不重归一化；不满足概率域检查就失败。finite input d=4仍是已有有限态定义，积分没有增加位移后的输出光子截断。

## 独立复Q矩阵路线

令局部实噪声协方差C=FFᵀ，β=(μx+iμp)/2（中心分布使整体负号无关）。定义N=E[ββ†]、M=E[ββᵀ]，则

    Q = I + [[N,M],[M*,N*]],
    X = [[0,I],[I,0]],
    S = (I−Q⁻¹)X.

平均相干态投影的Bargmann生成函数前因子为1/√det Q，二次型矩阵为S。系数使用归一化递推

    R_n = Σ_j S_ij sqrt((n_j−δ_ij)/n_i) R_(n−e_i−e_j),

其中n_i>0，R_0=1，奇数总阶为零。相较主路线，这里直接求逆复Q并递推归一化系数，不调用实倾斜协方差和未归一化Wick函数。Gaussian Fock表示是既有工具，参见[The Walrus Fock张量](https://the-walrus.readthedocs.io/en/stable/_modules/thewalrus/quantum/fock_tensors.html)及[协方差转换](https://the-walrus.readthedocs.io/en/stable/_modules/thewalrus/quantum/conversions.html)；本项目自行实现两条路线并核对，不主张新公式或算法首创。

## 局部下界和局部上界不能互换

经典边缘化使TV收缩。因此固定有限态混合输出与Gaussian目标之间的完整TV，至少为任一个四模式边缘TV；取多个块的最大值仍然有效，不能直接相加。扩大见证后下界提高，表示证据更强，不表示物理误差随实验轮次变大。

另由Cauchy–Schwarz，任意两组非负数p、q满足

    TV(p,q) ≤ 1/2 sqrt[ Σ(√p−√q)² · Σ(√p+√q)² ].

实现以(p−q)/(√p+√q)计算根差，避免近等根直接相减。该上界只约束代入的四/八模式分布，不能上推到完整144模式。这里已经算出小块完整TV，上界主要用于数值和公式一致性对照；**没有获得完整系统TV上界**。所有数值是浮点诊断，未封装严格有向舍入误差。

## 森林前缀与重排

森林算法在当前步仅使用历史和当前模式。若目标八模式集合被置于测量顺序最前，其前八步的所需Gaussian事件由该八模式协方差决定。最近点击选择在模式映射后保持一致；静态MI树使用同一模式对的未条件化MI及同一物理编号排序。对连续升序模式块，重编号保持排序关系。本轮另以完整144模实例核对固定前缀，不能仅凭口头推理忽略选择器或并列权重规则。

起点0的八模式是自然顺序的前缀；起点18、54、136则分别定义不同的重排算法。其小块律不是自然顺序算法在那些模式上的任意边缘。前缀后的数值失败也尚未穷举：本轮证明的是前八步法则及其误差，不能保证后续完整输出一定成功，更不能把成功样本条件化后的分布当作同一概率律。

若讨论全程轨迹，可以保留失败前缀并把本轮分布解释为在第八步停止的观测；若只讨论“完整二元串加单一失败符号”的输出空间，不能不加条件地把未来失败后的不同前缀都恢复出来。本轮不据此宣称完整二元输出的严格误差界。

## 校准范围

7项单元测试包含完整稠密部分迹、独立Bargmann矩阵、混合完整分布和Cauchy/边缘化检查。正式核验还将块密度的所有单模式约化与第29轮冻结密度比较，并用第30轮实际样本作16原子频率校准。后者只报告统计偏差，不用于挑选当前块、调门槛或续抽；共同随机数产生的六组样本不能当作独立重复实验。
