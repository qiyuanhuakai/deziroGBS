# 第37轮：先进经典工具、最新理论与九章

资料核查日期：2026-11-09。以下是适用范围对照，不是统一硬件、输入与误差要求下的速度排行榜。本轮比较四种点击保留启发式；条件互信息规则此前已经存在，此次只是接通森林接口并进行固定预算比较。

| 路线 | 原始来源中的能力与前提 | 本轮对应关系与尚缺工作 |
|---|---|---|
| FrugalGBS | 作者报告单CPU/GPU通过百模式GBS既有基准，并讨论可并行扩展；通过若干基准不等同于认证完整输出TV。 | 项目已有固定版本官方代码及小系统完整实现律枚举接口；本轮没有重新运行它，也没有同硬件胜出证据。下一轮应在本轮明确物理的同一目标上重建官方基线。 |
| Gaussian SVD + projected-creation-operator MPS | 2026年5月v2及npj Quantum Information论文，避免局部hafnian构造；效率依赖低纠缠及可控截断，包含九章2.0/4.0协方差基准。 | 森林保留预算与MPS键维数不能直接等价；需统一物理目标、阈值测量、截断误差及预处理成本。 |
| 大规模计数基准 | Goodman等2026年4月报告可扩展近似方法及1152模式计数数据比较。 | 本轮使用计数尾事件作为完整TV的统计下界；匹配计数均值或某组矩不提供完整TV上界。作者的领先表述不转写为本项目独立排名。 |
| 探测后Gaussian重置 | Lim 2026年10月给出任意干涉仪的O(Nη³)误差形式，η为存活率，并研究等压缩特殊构造。 | 具体有限规模需常数和损耗参数，不能把渐近阶直接当成144模或九章的数值质量证书。 |
| 损耗下平均情况/高概率理论 | Lim 11月1日：固定非零均匀损耗、各输入等且有界压缩、Haar平均误差；Angrisani–Mhiri 11月5日：热损耗及纯损耗、固定均匀压缩、Haar高概率，非Haar情形另需平坦性等前提。 | 本项目给定B,F实例及静态森林启发式不自动满足或继承这些结论。它们是必须追踪的新理论前沿，不是本轮采样器的误差证明。 |
| 九章4.0 | 实验团队预印本v3报告1024压缩输入、8176模式、最高3050个光子探测事件、25.6微秒/样本；超过10^42年的数字来自所讨论MPS资源外推。 | 本轮144模经典代理与该实验规模、测量和精度要求不同。既未模拟完整九章4.0，也未证明优于先进经典工具；实验论文的特定MPS外推也不是对所有后来经典算法的普遍下界。 |

与上述路线相比，本轮可交付的是可重放的选择/图结构记录、完整十步停止律的严格区间，以及固定新样本流上的大系统偏差检验。它加强了可审查性，但不替代全球分布质量和外部同目标比较。

本次扩展检索还补入三条相关边界，均核对原始arXiv摘要与版本元数据，未声称逐条审查完整证明：

- [Go–Jeong，2026-10-19](https://arxiv.org/abs/2610.27065)：固定损失数及均匀透射损耗下，常数存活比例的BosonSampling在Haar高概率意义下可多项式模拟。该文的固定输入光子模型不能不加转换地当作本轮给定Gaussian B,F实例的直接算法。
- [Shou等，2026-08-19](https://arxiv.org/abs/2608.19314)：完成任意压缩输入数的GBS hiding猜想相关证明，涉及N=o(sqrt(K))范围与近似实例生成。它补强困难性归约的一环；既不等于对全部有损实验的无条件困难性证明，也不与不同损耗/平均情况前提的可模拟性结果直接矛盾。
- [Dou等，2026-09-30](https://arxiv.org/abs/2609.38882)：研究GBS后处理函数期望的经典计算和被动网络平均情况。函数计算、给定实例统计量认证、完整分布采样是不同任务；本轮精确给定模型矩并非Haar平均值。
