# 第66轮：实际Gaussian-SVD张量与前沿工具、九章对照

2026-11-10。重新核对Gaussian-SVD/PCO的局部核和投影公式、作者数据页及九章4.0的MPS成本外推。其他路线保留同日原始来源的适用条件。

| 路线 | 原始来源 | 本轮对应关系 |
|---|---|---|
| Gaussian-SVD / PCO | [论文v2，第II.3节](https://arxiv.org/html/2512.10643v2) | 局部配对核和投影创建算子属于既有构造。本轮使用本项目已有GSVD与递推实现，保存核、占据、标量和实际有限张量；独立PCO复建与全局消元交叉核对，再用严格保真度认证实际binary64张量到原有理Gaussian输入的距离。未主张新GSVD算法或作者官方程序同机测速。 |
| 作者参考与计时来源 | [Zenodo数据页](https://zenodo.org/records/18045305)、[readme](https://zenodo.org/records/18045305/files/readme.txt?download=1) | 页面列出PCO包、通道分解包、说明及time log.zip；说明将D200结果定位为参考展示，并指明计时日志用途。本轮只核对清单与用途，没有重新计算作者计时。第22轮144张量复现已完成，本轮不重复计为新成果。 |
| 混合态输入来源 | [同一论文式38及附录C](https://arxiv.org/html/2512.10643v2) | 纯态加经典位移分解仍要求半正定噪声。第27轮指定文件的PSD失败、第28轮邻近可构造模型及第29—30轮同通道采样均保留。本轮60项是固定位置的位移，不是连续噪声积分或作者原实验模型闭合。 |
| Frugal与计数基准 | [Frugal](https://arxiv.org/abs/2511.14923)、[Goodman等](https://arxiv.org/abs/2604.12330) | 前者的144模前缀研究与后者作者报告的最高1152模计数基准均与本轮指标不同。没有新增外部工具运行或同质量速度排名；小系统完整TV与大规模统计指标不能互相代替。 |
| 固定损耗理论 | [Lim](https://arxiv.org/abs/2611.01434)、[Angrisani–Mhiri](https://arxiv.org/abs/2611.08444) | 位复杂度、统一压缩、Haar平均/高概率及平坦性等条件仍须逐条匹配。本轮指定2/3模输入证书不证明144模或九章指定线路满足这些渐近前提。 |
| 特殊图与链 | [Anand等](https://arxiv.org/html/2511.16558v3)、[Chen等定理12](https://arxiv.org/html/2504.02740v1) | 第63—64轮已有实际链及停止律结果，后续仍需同误差成本与较大图混合证书。本轮GSVD实际输入审核不解决该独立问题。 |
| 九章4.0 | [原论文v3](https://arxiv.org/html/2508.09092v3)、[Nature论文](https://www.nature.com/articles/s41586-026-10523-6) | 作者报告1024压缩输入、8176模式、最高3050探测事件和25.6微秒/样本。本轮最大3个物理模式、实际键不超过6，核验420个公开样本和完整有限字概率律；没有九章规模模拟或吞吐胜出。文中的拟合键维数及指定MPS成本外推不等于所有经典算法的下界。 |

本轮向前推进的是指定输入到实际有限张量再到完整采样程序的证据连接。无截断核恢复仍是浮点诊断；严格输入误差来自对实际保存张量的直接保真度计算。后者目前依赖指数规模小Fock箱，不能包装成大规模可扩展认证。
