## 可复核的有限参数代入

第一篇 G.4、G.28、G.32、G.40、G.76、G.101 给出以下量：

```text
n = sinh(r)^2; a = n + (1+n)/m; b = eta*a + (1-eta)*beta
q = eta^2*a*(1+a)/(b*(1+b)); C = e*(1+(m+1)*n)
D = max(0, ceil(log((C-1)/(delta*epsilon_L1^2))/log(1/q)) - 1)
Q_D = binomial(m+D,D); S_D = 3*(6e)^D*C
```

`experiments/iteration23_literature_budget.py` 仅检查这些公式在具体参数下的数值，并用 80 位计算复核最小整数 D。ε_L1 是有符号近似的 L1 截断预算；不能当作已经实现的完整采样 TV。Q_D 是确定性基展开的系数数目；S_D 是随机点估计方差的粗上界。大的充分上界不提供实际运行时间下界，也不能否定论文的渐近结论。G.98 的逐阶能量可能改善此粗界，尚未实现。

检测重置论文的 S28 明确选 C₃=max(1000,19683/200·[8n³+(94/9)n²+(20/9)n])，并说明 η>0.1 时此通用界取到1。因此它不能认证当前 η=.65 面板的小误差；这仍不是实际误差大的证据。其 S30 还把等待时间反演视作算术操作，不是已完成的比特复杂度或运行时间测量。

## 本项目的独立推论与下一步

纯核心 Schmidt 秩大，只限制这种纯态近似；它不排除有损计数分布存在高效经典采样器。已验证的 MPS 成本与直接输出算法应并列比较。

也不能把一般 U 的平坦性前提当作恒真。取 U=I，理想等压缩计数全部落在各模式偶数事件 E；热参考有 τ_a(E)=((1+a)/(1+2a))^m。Cauchy–Schwarz 给出 1+χ²(P||τ_a) ≥ 1/τ_a(E)，随固定压缩下的 m 指数增长。这不证明本项目随机局域线路违反前提，只给出不能省略该前提的反例。

对一个已经获得 PNR TV 保证的采样器，确定性阈值化由数据处理保持该上界；实现中的失败、截断、随机数和舍入仍必须另计。下一轮先核对小系统完整分布、有符号截断和合法采样转换，再考虑颜色随机化与有限成本。已有 Meixner 代码只作为可比较的独立实现，不能据名称视为复现了这些新算法。
