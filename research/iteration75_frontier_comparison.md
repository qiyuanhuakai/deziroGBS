# 第75轮前沿范围

本轮Frugal基线为[官方提交fa8b796](https://github.com/tomdodd4598/FrugalGBS/commit/fa8b796f2afebd4845a2e335e457735952617ef8)，使用既有Windows ABI与CUDA宿主布局兼容修改。增加192/288/384模板实例及编译期索引字面量；268995项与官方原数组字节相同。CPU FP64 AVX2、GPU FP64，Ultra9 275HX、RTX5080 Laptop 16GB，CPU16线程。初始化、采样和输出转换计入，库加载/共同输入读盘排除。

固定四模同准确性点击任务，Frugal CPU K4比本项目GPU8分支快25.800倍。固定144输出、两个r=1.1输入，PNR prefix31转点击比Frugal CPU K2/K3快11.616/12.028倍；其理想TV上界0.080825%，两Frugal数值律的全零事件误差下界27.77846%/35.92013%。这些边界有不同算术/RNG假设，不构成全浮点认证；也不覆盖高输入秩。

192输出64输入的直接点击4分支原始速度比Frugal CPU K2/K3快49.85/59.01倍；大输入完整TV未获界。九章3.0的[1.27微秒/样本](https://arxiv.org/html/2304.12240v2)对应144物理模式1152探测箱，本次192输出每样本821.225微秒，原始时间慢646.63倍。与[九章4.0](https://arxiv.org/html/2508.09092v3)1024输入8176输出相比，已实测直接点击128/384仍小8/21.29倍，低秩PNR的2个输入小512倍。

[Lim, Boson sampling is fragile to loss](https://arxiv.org/abs/2611.01434)，2026-11-01，针对固定均匀损耗、Haar平均误差和相应输入假设给出多项式采样复杂度。部分模式占据的充分条件ηcosh(2r)<1；当前r=1.4、η=.43给出3.5487，需η<.12117才满足。纯态低秩实例η=1也不满足这个条件。未实现论文估计器，不列入本机速度排名。下一轮需要将其有限阶估计落实为可执行实验，不能以渐近界代替墙钟数据。
