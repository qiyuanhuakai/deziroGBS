# 待验证：先抽精确总光子数，省去无点击时间求根

本文件是第76轮等待串行计时期间形成的推导及下一步实验设计；没有对应执行结果，不作为已实现的速度或质量结论。

## 等压缩、无位移纯态的正系数形式

设n个输入的压缩参数均为t，V为被动等距矩阵。已有k个有序光子端口后，将第75/76轮Hermite递推固定在τ=0（分母为1），得到H_k(y)。每步为

H_{k+1} = Σ_j V_ij (∂_j − t y_j) H_k。

每一步的原始一般τ递推都有共同因子(1−τ²t²)^(-1/2)，故相同k的多项式等于H_k/(1−τ²t²)^(k/2)。将H_k按次数分组，定义W_d=Σ_{|ν|=d} ν! |h_ν|²≥0。未归一化、已经减去k个光子后的总数生成函数为

F_k(τ) = (1−t²)^(n/2) Σ_d W_d τ^d (1−τ²t²)^(-n/2−k)。

应独立检验该式的每个系数，而不能只检验τ=1的总和。k=0给出输入总数分布；k=1的全端口求和等于F_0'(τ)；k=2应与完整Wick展开逐项一致。

固定初始总光子数N，当前剩余数为R=N−k。归一化所需系数为[τ^R]F_k。每项仅当R−d为非负偶数时贡献

W_d · t^(R−d) · (n/2+k)_{(R−d)/2} / ((R−d)/2)!。

公共因子(1−t²)^(n/2)在端口条件概率中约去；所有项非负。下一个端口i的权重使用F_{k+1,i}中τ^(R−1)的系数；全部端口之和应等于R倍当前系数。最后一个光子只读取候选多项式的常数项，可显式检查端点与偶宇称。

初始N=2J，J服从形状n/2、参数t²的负二项分布。可由Gamma–Poisson混合抽取半整数形状，但必须检查有限随机数和整数存储范围。禁止把超预算N丢弃后重采样，因为这会改变目标律。

## 复用第76轮共享正范数

活动多项式基列为p、b_jp、b_j†p。将每一单项式行的阶乘权重再乘上述剩余总数系数，构造加权QR。无位移下p列系数为零。全部端口复用该QR范数；正交真空上升残差应按原多项式次数d+1的权重计算，不能沿用未条件化的普通范数。

可能收益是完全删除无点击生存率求根，以及固定t后减少反复重建；仍有光子前缀次数带来的组合复杂度，不能提前宣称高能量任意维度加速。

## 实验门槛

1. 用独立Fock递推逐系数检验k=0～8、N=0～32的生成式及端口求和恒等式；同时验证单模解析分布、双模干涉与多输入随机等距矩阵。
2. 先在两个输入上实现完整条件采样，保留所有光子，无Gaussian合并；比较第75轮强四模完整分布及144输出的速度。
3. 对更多输入测试资源上限。任何稀有大N导致的资源拒绝都必须公开，不能把成功子集当成无条件采样。
4. 再研究固定剩余N下的Gaussian合并或其他受约束近似。仅强制最终偶宇称/正确总数并不足以证明完整端口分布正确；需要新的事件和完整小系统检验。
