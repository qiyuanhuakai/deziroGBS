# 第63轮：图分布路线与先进工具、九章对照

2026-11-10重新核对以下原始论文及作者数据页。检索用于确认适用范围，不把搜索无命中当作首创证明，也不对不同目标、不同误差条件的工作作统一速度排名。

| 路线 | 原始来源 | 与本轮的关系及尚缺条件 |
|---|---|---|
| 特殊图分布 | [Anand等v3，2026-11-06](https://arxiv.org/html/2511.16558v3) | 论文已给多项式采样构造。本轮独立复建其双层匹配投影，并补查有限字CDF次序及物理条件；最大8点，精确表有指数成本，未运行JS链。不能把图分布算法推广成任意复Gaussian阈值GBS算法。 |
| Frugal | [原论文v1](https://arxiv.org/abs/2511.14923) | 作者报告百模实验常用统计基准的优势。项目第61—62轮已有实际144模程序顺序和有限字混合审计。本轮图法没有相同目标的144模结果，也没有可比较吞吐；统计基准表现不能代替完整TV保证。 |
| Gaussian-SVD / PCO | [论文v2](https://arxiv.org/abs/2512.10643)、[作者数据和代码](https://zenodo.org/records/18045305) | 面向有限纠缠的Gaussian到MPS构造，作者页确实提供PCO及通道资料。项目第22轮已重建144站点参考张量，第27轮已核对部分协方差来源；尚待闭合有效原始输入到核/占据/有限MPS/采样链。本轮不重复这些旧工作为新成果。 |
| 固定损耗平均情形 | [Lim](https://arxiv.org/abs/2611.01434)、[Angrisani–Mhiri](https://arxiv.org/abs/2611.08444) | 固定损耗、相应输入条件及Haar平均/高概率前提需要保留。图法使用非负邻接结构，是不同适用域。指定九章线路是否满足条件及有限资源成本仍需单独证明；Lim的既有比特复杂度讨论不应被遗漏。 |
| 检测重置 / 相位扩散 | [重置论文](https://arxiv.org/abs/2610.06526)、[相位扩散论文](https://arxiv.org/abs/2608.31089) | 本轮沿用第60—62轮的适用域审查，没有新增执行或最新版本核对，不主张扩展其结论。 |
| 九章4.0 | [原论文v3](https://arxiv.org/abs/2508.09092)、[Nature论文](https://www.nature.com/articles/s41586-026-10523-6) | 作者报告1024压缩输入、8176模、最高3050探测事件，原论文给25.6微秒/样本。本轮8点特殊条件图律与之不是同一问题规模或探测分布。九章文中针对指定MPS方案的估算不能当作所有经典算法的下界，本轮也没有反向证明九章完整分布可在可用资源内模拟。 |

本轮实际增加的能力是：同一小图目标、两种独立计数、完整有限字概率及有效Gaussian条件事件之间的可检查对应。下一步应落实有明确转移和误差预算的有限链，而不是从平稳完美质量较大直接宣布高吞吐。
