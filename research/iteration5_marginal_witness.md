# 第五轮：由独立留出样本校准的边缘事件见证

日期：2026-11-04。实现：`src/gbslab/marginal_witness.py`。

## 要解决的证据缺口

第四轮的大模式全局 TV 上界受目标点概率计算预算限制。高点击样本常常只能按最坏分数 1 处理；官方 Frugal 还需要额外的实际路径概率审计。新的见证只使用完整输出位串和给定 Gaussian 协方差，不需要任何采样器的 logQ，也不对全系统位串求点概率。这样，候选采样器与官方 Frugal 可以接受完全相同的检查。

它提供的是**完整系统 TV 的统计下界**。能够拒绝误差容差，不能接受完整分布接近；即使所有窗口均未拒绝，也不能接受这些窗口自身的 TV 接近。本模块不是一种新的 GBS 采样算法。

## 目标边缘分布

给定零均值 Gaussian 态、`xxpp` 排列、`hbar=2` 和阈值探测，对小窗口 S 的每个二进制模式精确枚举目标边缘概率 `P_S`。这里“精确”指没有截断概率模型，实际算术仍然是受保护浮点计算。

对任意 `T ⊆ S`，全部无点击的概率为

\[
v(T)=\det\left((V_T+I)/2\right)^{-1/2}.
\]

若窗口模式 x 的零位置为 Z、点击位置为 C，则

\[
P_S(x)=\sum_{T\subseteq C}(-1)^{|T|}v(Z\cup T).
\]

采用现有 `ThresholdModel.marginal(S)` 的缓存和 Möbius 变换。窗口中物理模式 j 对应全局矩阵的行列 j 与 `j+m`。边缘位串整数掩码的第 j 位对应传入窗口列表的第 j 个模式；无需将窗口放在协方差前端，也不能把 `xxpp` 当成 `xpxp`。

每个 b 模式窗口需要 `2^b` 个真空子集。该指数仅依赖窗口大小，不依赖全系统模式数 m；物理性检查仍有全矩阵成本。默认宽度为 8，窗口为前段、中段、后段、均匀稀疏跨区各一个；小模式数造成的重复窗口会被删除。所有窗口由模式数确定并在抽样前冻结。

## 学习见证与检验见证必须分开

一次固定批次共 N 条完整样本，抽样前指定前 `n_pilot` 条为 pilot，剩余 `n_test=N-n_pilot` 条全部留出。采样器在 pilot 后保持原样；pilot 只用来选择见证事件。

对第 j 个窗口，用 pilot 频率选择

\[
A_j=\{x:\widehat Q_{j,\mathrm{pilot}}(x)>P_{S_j}(x)\}.
\]

等号处不选取。`A_j` 是一组确定的模式掩码。它可以包含多个模式，因而将分散在多个输出上的偏差汇总到一个事件中。每个窗口仍只消耗一个 Bernoulli 见证的误差预算，不为 `2^b` 个模式分别做检验。

留出数据仅用于计算

\[
\widehat q_j=\frac1{n_{\mathrm{test}}}
\sum_{t\in\mathrm{test}}\mathbf1[X_t|_{S_j}\in A_j],
\qquad
p_j=\sum_{x\in A_j}P_{S_j}(x).
\]

不在留出数据上重新选择 A，不因留出差异为负就取补集、反转方向或取绝对值，不把 pilot 样本加回验证计数。重复出现同一个位串是合法的 iid 结果，不能简单地用位串去重来“确保独立”；必须确保使用的尝试行互不重叠。

## 单侧界与多重比较

向当前“目标模型 × 采样方法 × 本见证套件”预先分配总误差预算 `alpha`。若计划 J 个窗口，则每个窗口预算为 `alpha/J`，包括随后发生数值失败的窗口。采用固定的一侧 Hoeffding 界：

\[
r=\sqrt{\frac{\log(J/\alpha)}{2n_{\mathrm{test}}}},\qquad
L_j=\max(0,\widehat q_j-p_j-r),\qquad L=\max_j L_j.
\]

在给定 pilot 后，各事件固定。对留出部分的 Bernoulli 均值应用一侧 Hoeffding，再对所有计划窗口取并集界，至少以 `1-alpha` 的概率得到

\[
\operatorname{TV}(P,Q)\ge L.
\]

不同窗口可以重叠；并集界不要求窗口之间独立。不同方法、不同目标及其他检验的预算由调用者在外层再分配。本模块的 `alpha` 不能与旧 D1 的整套预算重复使用。第五轮主实验计划将总预算 0.05 中的 0.025 分给原 D1 套件，另外 0.025 分给本套件的 14 个比较，故每比较 `alpha=0.025/14`。以 4 个窗口、256 条 pilot、768 条留出样本为例，半径约 0.0709。该示例是预定预算的算术，不是实验结果。

如果 `L>epsilon`，返回 `rejected`；否则返回 `insufficient_evidence`。降低 L 不足以证明某算法全局 TV 更小，未拒绝也不足以证明对实验硬件的复现。

界的正确性不取决于 pilot 是否足以学到最优事件。pilot 不足会降低检验功效，但不会使留出界失效。稀疏的 `2^b` 模式直方图可能需要更多 pilot；应在独立下一轮预先调整预算，不能看当前留出结果后挑选窗口宽度或划分比例。

## 数值失败、抽样失败与协议

输入模型必须是物理 Gaussian 协方差。任何完整抽样批次的失败、中断或缺少请求的样本都不能被当成已经完成的 iid 批次。`sampling_failure` 会立即产生 `evaluation_failed`，不重试、不补抽、不从成功子集计算界。缺少协议时只返回描述性统计；协议与样本行数、pilot 大小、窗口散列或固定划分规则冲突时不计算统计下界。

数学上的单次输出空间仍包含显式失败符号 `⊥`，`P(⊥)=0`，见证函数在 `⊥` 上为 0。目标与采样器的距离是这个扩展空间上的 TV。对预定 N 次尝试，只有全成功事件才报告下界。错误拒绝事件仍包含于未条件化实验的 Hoeffding 尾事件；这不允许宣称“条件于获得成功批次”仍有相同覆盖率，也不能把失败后再试得到的批次装成第一次批次。该下界没有额外保证成功条件分布的 TV 下界。

若个别窗口的目标边缘因浮点相消失败，保留失败记录并使用其他窗口，但继续按原 J 分配预算。所有窗口都失败则没有有效下界。没有将数值保护裁剪等同于向外舍入的数学证书，`strict_floating_point_certificate` 恒为 false。

## API 与可复现记录

```python
from gbslab.marginal_witness import (
    default_marginal_windows, fixed_split_protocol, assess_marginal_witness,
)

windows = default_marginal_windows(modes, width=8)
protocol = fixed_split_protocol(1024, 256, windows=windows,
                                source="prespecified_iteration5_batch")
# 在抽样前将 windows、protocol、alpha 和算法输入写入实验计划。
# 随后生成固定算法的第一批 1024 条完整样本。
report = assess_marginal_witness(
    covariance, samples, windows=windows, pilot_size=256,
    alpha=.025/14, epsilon=.1, protocol=protocol,
)
```

结果保存目标协方差散列、完整样本及两个分区各自的散列、窗口清单与散列、每个 pilot 学出的事件掩码及散列、全部边缘目标概率、pilot/留出模式计数、固定单侧方向、误差分配与下界。外层运行器另需绑定采样器二进制、参数、完整协方差来源和原始样本。协议记录是对真实操作的声明，不能用哈希证明任意外部采样器诚实。

定向测试覆盖已知热态/TMSV分布、错误相关结构、零概率支持、稀疏窗口与 xxpp 索引、空事件与全集、pilot 不重复用于检验、留出变化不改变事件或方向、完整有限二项试验枚举验证覆盖率、窗口失败预算不转移，以及无效/重试/未完成协议。这些测试检验逻辑与算术，不会把单元测试夹具冒充实际 iid 实验。

## 与 Frugal 和九章声明的关系

本轮重新检索的一手来源仍支持第四轮范围审计：Frugal 已发表结果对比 J2 的 144 位阈值输出及 J3 的 144 位粗粒化输出，使用低阶累积量、可计算扇区 XEB 或总点击分布等指标；并未提供完整九章四号分布的复现。新见证可以增加同目标比较的可证伪性，但不能自动补上 Frugal 或本项目缺失的全 TV 上界。

来源：Dodd et al., *A fast and frugal Gaussian boson sampling emulator*, Science Advances 12, eaef8431 (2026), [最终正文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13665930/)；[作者预印本](https://arxiv.org/html/2511.14923v1)；[官方公共实现](https://github.com/tomdodd4598/FrugalGBS)。最终正文直接打开遇到浏览器验证，本次范围核验使用其检索索引正文，并以可读预印本交叉检查；没有据此声称复现作者 J2/J3 数值结果。

本模块作者另外只读审查了第五轮 C++ 前缀缓存、Python 包装器及缓存测试，没有参与修改这些文件。审查未发现阻断问题。核对的源代码 SHA-256 为 `c74c377e81137786cfdd2ae02c66967f3c7920393adf067ab9b3c4348a7fbd28`，二进制 SHA-256 为 `a8d5a830e7167aab20f829bee74bc404736f2551ff42e6e48491caf301d0fc3f`。实现作者执行的门禁记录位于 `results/iteration5_prefix_validation/validation.json`；独立复核确认其中源码、包装器、测试和二进制散列与磁盘文件一致，13 个测试全部通过、没有跳过，包含 24 个详细检查。这里区分实现作者执行测试与独立审查读取证据，没有将它们叙述成两次独立运行。

核心不变量是：单个缓存仅用于固定协方差、固定选择器、k、概率核和测量顺序的一批样本。树的路径编码所有已测零与点击，不会把只有相同保留点击集的两个不同历史混为一谈。缓存存放成功计算后的 double 条件概率、保留模式、相消指标和分母；物理模式 ID 0…255 可由 uint8 正确表示。

首次未命中时，程序从同一基础协方差重新构造 `State`，按原测量顺序重放此前全部零投影，历史点击列表继续保留全部点击。使用同一个 `project_zero` 与条件核，没有改变行列排序或插入概率平滑。条件核中的单步真空缓存会在实际计算处重新设置代次，不能把旧 Gaussian 状态下的值带入新状态。

缓存命中后若选择了此前未访问的零边，该零更新在下一个条件概率之前重放；若更新失败，会恢复原零步骤的上下文，并在消耗下一次均匀数之前中止。已存在子节点说明对应边此前已成功通过更新。最后一步原程序本就不更新无需再用的状态。容量耗尽时停止加入节点，后续按原核求值，没有淘汰后误把非根前缀插为根的路径。任意非恒等测量顺序由固定顺序加树深度唯一确定，物理位串输出保持原模式编号。

缓存中的条件概率是固定函数 `q_i(x_<i)` 的重复使用，而不是根据以前样本拟合的频率。即使缓存跨越 pilot 与 heldout 累积，命中与否、缓存容量和既往样本内容均不改变该函数。因此，在数值路径等价的限定下，给定 pilot 之后留出部分的分布仍是同一个 Q；缓存状态变化不会破坏本见证要求的固定采样律。相反，如果今后把缓存改成统计估计、近似合并前缀、依赖访问频率的舍入或调整概率，就必须重新论证这一点。

已有测试对小系统所有前缀进行注入均匀数遍历和复访，逐值比较样本、条件概率、保留集与 logQ；同时覆盖容量 1/3/17 饱和、m=1、k=8、非恒等顺序、TMSV 支持、64/100/256 模式编号、内置 PRNG 消耗及预热后的数值失败。完整 Q 枚举与树相互独立，故单独“枚举 Q 相等”本来不足以检查缓存读取路径；遍历复访的设计补足了这一点。大型模式测试使用热态，是存储与路径检查，不是一般高亮度 GBS 质量证书。

诊断中的条件核调用、投影、修正和行列式次数表示实际执行的计算；命中时不会重复计入这些计算。它们的减少不能解释为概率精度改善。每个被命中的前缀都曾在当前批次中完整计算，因而整批概率/相消极值仍由首次计算覆盖。缓存容量字节数是 trie 向量载荷的分配容量，不等于已触碰页面的 RSS，也不包括矩阵、样本缓冲区及分配器开销。

该实现属于对既有近似条件链的有界 memoization，可理解为按需展开并复用固定二叉决策树。本轮可报告同一 Q 的工程加速，不据此主张原创 GBS 算法或改进单样本最坏复杂度。小模式数时，完整非叶树只有 `2^m-1` 个节点，预热后可能接近每条样本 O(m)；大模式固定容量下，收益依赖访问分布和批量，不能外推小模式长批优势。
