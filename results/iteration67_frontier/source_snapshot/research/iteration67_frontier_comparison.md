# 第67轮与图采样前沿、先进工具及九章对照

2026-11-10，重新核对Anand等v3的加权链命题与Chen等定理12。其他路线沿用同日第66轮的原始来源核对，不重复计为新增工具运行。

| 路线 | 原始来源 | 本轮位置与限制 |
|---|---|---|
| 特殊图GBS | [Anand等v3，命题2.1、第4节](https://arxiv.org/html/2511.16558v3) | 原文通过双层图的加权完美匹配得到目标，并用增权确保接受质量。本轮不重新发明该构造，补充5张指定小图在相同条件TV门槛下的精确期望随机字成本。多项式渐近结论不直接给出本轮实用最优α或实际速度。 |
| 较快JS混合界 | [Chen等，定理12](https://arxiv.org/html/2504.02740v1) | 正文保留统一λ的显式依赖，摘要的简写不能当作无权重代价。我们的两类边权αc²与α不同；不能直接把统一λ界当作本轮指定链的数值证书。140个完整有限律采用直接精确计算，也不构成更好的大图混合定理。 |
| GSVD/PCO | [论文v2](https://arxiv.org/html/2512.10643v2)、[作者资料](https://zenodo.org/records/18045305) | 第66轮已经把实际GSVD有限张量接到60项完整程序，本文图条件目标不同。未对官方GSVD代码新增同机测速，也未证明图链可替代一般复数输入。 |
| Frugal及计数基准 | [Frugal](https://arxiv.org/abs/2511.14923)、[Goodman等](https://arxiv.org/abs/2604.12330) | 大规模统计指标、计数任务与本轮小图完整条件TV不同。没有跨任务速度排名；此前144模前缀审核也不能当作本轮完整图律证据。 |
| 损耗理论 | [Lim](https://arxiv.org/abs/2611.01434)、[Angrisani–Mhiri](https://arxiv.org/abs/2611.08444) | 输入族、损耗、平均或高概率和位复杂度条件仍需各自核对。本轮图条件分布的证书不替代指定实验线路适用性检查。 |
| 九章4.0 | [原论文v3](https://arxiv.org/html/2508.09092v3)、[Nature](https://www.nature.com/articles/s41586-026-10523-6) | 作者报告1024压缩输入、8176模式、最高3050探测事件及25.6微秒/样本。本轮最大4个物理模式，仅特殊无碰撞条件目标；报告的是精确期望步骤和随机字，不是同目标同质量样本率。文中指定MPS外推不等于所有经典算法下界。 |

本轮可审核的新证据是：接受质量与有限混合应一起用于资源决策，且最省转移数不一定最省随机字。这是冻结小面板内的结果，没有声称超过九章或现有通用GBS工具。
