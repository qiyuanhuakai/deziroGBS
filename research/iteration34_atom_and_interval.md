# 选定完整输出的重叠界与精确Gaussian矩阵区间

## 完整原子不是前缀

设S为若干互不相同的完整m位输出串，不指定的模式均明确是真空。目标P在每个x∈S上的概率包络为l_x≤P(x)≤u_x，代理成功概率为q_x。只要P、Q各自归一化，且P没有失败符号，就有

    TV(P,Q) = 1 − Σ_x min(P(x),Q(x))
            ≤ 1 − Σ_{x∈S} min(l_x,q_x).

这不需要目标的完整2^m表，也不需要知道S以外代理条件如何取值。未知输出质量全部保留，不根据少量好看的前缀推断尾部。计算本身是标准重叠恒等式的应用，不主张新定理。

每条选择路径遇到数值失败时，Q在该失败前缀的全部到达质量计入失败。不同已见失败前缀不能互为祖先，因此可去重相加得到f_seen。未选择分支可能还有更多失败，不把f_seen当作完整失败概率。有效的下界为

    max[ Σ_x max(l_x−q_x,0), f_seen+Σ_x max(q_x−u_x,0) ].

两项分别控制P−Q的正质量与负质量。完整审核归一化的精确目标表时，上下界合并为真实TV；目标有区间时留下相应宽度。所有成功原子、已见失败与未选择分支恰好满足总质量1。

## 单次原生轨迹的定义

本轮实际调用wire原生实现，固定最近4点击、链、自然顺序，使用cache_size=0。对每条选定完整串，从空历史开始依次计算所有前缀；现有接口在空历史时使原生零条件状态失效。目标串的下一位概率为零时停止；数值失败时停止；不调用随机数、不重抽。

重复前缀每次都真实重新计算，二进制条件值必须一致，否则正式工作失败。所得质量对象是这一明确的无跨轨迹条件缓存、从空状态启动的**单次尝试**法则。它不自动认证默认8192缓存、其它查询历史或跨样本相关性。复用的第32轮数据仍只表示其冻结的八模式法则。

若有M个选定原子，完整轨迹至多需要mM次原生调用。主审核再用前缀树去重重建概率，独立审核逐原子乘积计算。同一层的上下界分别对理想Bernoulli及独立53位均匀网格模型计算，后者以ceil(2^53 q)/2^53作为点击率，仍不证明某个确定性PRNG独立。

## 整数残差的证书

输入V的每个binary64条目按其精确dyadic值解释；Q=(V+I)/2的加法和除法在有理数中进行。浮点Cholesky及求逆只提出下三角矩阵R，R的条目同样解释成精确dyadic数。将Q、R分别转为共同2的幂分母上的整数矩阵，以Python大整数矩阵乘法计算

    E = R Q Rᵀ − I, δ = max_i Σ_j |E_ij|.

R对角非零，E精确对称；若δ<1，则RQRᵀ的全部特征值位于[1−δ,1+δ]，从而证明Q正定。由于维数为2m，真空行列式函数满足

    det(R)/(1+δ)^m ≤ 1/sqrt(det Q) ≤ det(R)/(1−δ)^m.

这些端点先按Fraction精确计算，再向外舍入到128位dyadic网格；中间结果不转浮点。诊断中的浮点δ仅供显示，不用于接受判定。

令Y=RᵀR。由Q^-1=Rᵀ(I+E)^-1R，有

    |(Q^-1)_ij−Y_ij| ≤ δ/(1−δ) sqrt(Y_ii Y_jj)
                       ≤ δ/(1−δ) (Y_ii+Y_jj)/2.

这给出2×2/4×4主块的有理数区间。用完整Leibniz行列式展开包住det((Q^-1)_SS)，并以整数平方根向外包住其倒平方根。Jacobi恒等式给出删去0/1/2个模式后的真空概率函数；再经容斥得到指定完整点击原子的区间。区间运算可能因相关误差丢失而变宽，不能把负下端点直接冒充负概率。本矩阵模块保留原区间，不做物理概率投影。

这个证书仅证明Q正定及相关行列式函数的区间，**不证明V+iΩ半正定，也不证明V是某个实验协方差**。后续补查已对既有144模存储矩阵找到严格负的有理数Rayleigh见证，因而它按精确条目解释时不满足量子不确定关系，详见[物理性审计](iteration34_physicality_audit.md)。相应行列式函数区间不能直接作为物理TV保证。

## 有独立物理保证的对照

热态V=(1+2^-b)I有精确点击率1/(2^(b+1)+1)。秩一位移模型取V=I+aaᵀ，a的每个分量为固定符号乘2^-s；本面板的构造运算都可精确二进制表示。这是将一个实Gaussian经典位移施加给真空的协方差，物理有效性不依赖浮点特征值容差。

删去k个模式后，真空函数为[1+(m−k)2^-2s]^-1/2。因此完整k点击原子的概率有二项容斥式，可用256位dyadic根区间计算。也可以写成全为非负的积分：

    E_{z~N(0,1)} [ (1−exp(−2^-2s z²/2))^k
                  exp(−(m−k)2^-2s z²/2) ].

独立核验采用该正积分，避免重复相消公式。热态和秩一物理对照的全局上界因而不需要全目标表；这些低强度、特殊结构的成功不能外推为一般144模GBS质量保证。

这些控制有非负的经典相空间表示，属于可直接经典模拟的输入；例如先抽取经典位移，再按给定相干幅度抽阈值结果。它们用于检验审核工具，不是新的困难GBS算法或量子优势反例。相关充分条件见[Rahimi-Keshari、Ralph与Caves，PRX 6, 021039 (2016)](https://doi.org/10.1103/PhysRevX.6.021039)，现有阈值经典态采样接口见[The Walrus文档](https://the-walrus.readthedocs.io/en/stable/code/samples.html#thewalrus.samples.torontonian_sample_classical_state)。本轮不执行这些第三方实现。

## 界的局限与完整证据

若目标在选定输出上的总质量很小，则重叠界必然接近1，即使每个已算原子都极准。增加原子只会改善界，但原子数、原生调用及目标计算成本也增加。本轮保存这些无法收紧的结果。

小系统用有理数消元独立核对补集行列式；大矩阵换乘法结合次序复核整数残差；已有144模矩阵另作高精度直接补集Cholesky；正积分和完整有限法则分别交叉验证目标与审核结果。高精度数值交叉检查本身不替代上述有理数区间证明。
