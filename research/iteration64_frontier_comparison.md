# 第64轮：匹配链实现与先进工具、九章对照

2026-11-10。本轮直接核对匹配链原始规则、图GBS构造及较新的混合时间论文；其他GBS工具及九章比较沿用同日第63轮已经核对的原始来源，未新增对应路线运行。

| 路线 | 原始来源 | 本轮对应关系 |
|---|---|---|
| Jerrum–Sinclair链 | [1996第12.4节，印刷页495](https://www2.stat.duke.edu/~scs/Courses/Stat376/Papers/ConvergeRates/JerrumSinclair.1996.pdf) | 原文给惰性加/删/换边和Metropolis接受。本轮明确一般有理边权比，并独立验证详细平衡、完整有限核、真实轨迹和停止律。原文的统一权重展示与本轮加权推广分开说明。 |
| 较新的JS混合界 | [Chen等，Theorem 12](https://arxiv.org/html/2504.02740v1) | 摘要的简写针对常数统一λ；正文定理保留显式λ依赖，不能说其只处理常数而无一般λ表达。c=1时本轮边权统一，可以进一步核算该类界；α随n增长时不能丢掉λ因子。c≠1的两类不同边权需要额外论证，不能直接套用统一权重结论。 |
| 特殊图GBS | [Anand等v3](https://arxiv.org/html/2511.16558v3) | 第63轮已验证目标构造，本轮实现链并区分平稳条件分布与首次命中。30组小状态空间有限步结果不等于重新证明大图多项式混合或获得实用运行常数。 |
| Frugal | [原论文](https://arxiv.org/abs/2511.14923) | 项目此前已有实际144模前缀误差和有限字混合审计，本轮图链目标不同，不与其直接比较样本率。有限统计检验表现与完整TV证书仍须区分。 |
| Gaussian-SVD / PCO | [论文v2](https://arxiv.org/abs/2512.10643)、[作者代码/数据页](https://zenodo.org/records/18045305) | 第22轮参考张量重建、第27轮来源核对已存在；待补有效输入到核/占据表的完整绑定。本轮没有新MPS运行，不能把局部链的进展算作该路线提升。 |
| 固定损耗理论 | [Lim](https://arxiv.org/abs/2611.01434)、[Angrisani–Mhiri](https://arxiv.org/abs/2611.08444) | 平均/高概率、输入及损耗前提继续保留。本轮的指定小图精确条件律不能替代这些渐近理论，也不提供指定144模或九章线路的新适用性证书。 |
| 九章4.0 | [原论文v3](https://arxiv.org/abs/2508.09092)、[Nature论文](https://www.nature.com/articles/s41586-026-10523-6) | 作者报告1024压缩输入、8176模、最高3050探测事件，原论文给25.6微秒/样本。本轮最大3个原图顶点、6个双层顶点与32个匹配状态；目标为特殊条件分布。没有九章规模完整模拟或同质量速度优势结论，指定MPS构造估算也不被当作通用经典下界。 |

本轮把“平稳质量大”与“有限程序准确”之间的缺口转成了可检查数据：量化偏差、有限步偏差、条件化和失败概率各有对应证据。最大已观察到的偏差来自有限混合与不当停止规则，64位量化误差在此面板很小，但仍被精确保留。
