# 第73轮方法：解析光子跳变、GPU 随机数与 Frugal AVX2

## 解析光子跳变的 Gaussian 多项式表示

设 Gaussian 正规序矩泛函为 `L_{X,w}`，其中物理协方差为 `I/2+X`。`X` 可以不正定；这里只计算解析矩，**没有把不正定的 P 表示当作实概率分布抽样**。输出模式 m 的光子跳变对应

\[
f_m(z)=\tfrac12[(a_m^Tz)^2+(b_m^Tz)^2],\quad
a_m=(\Re V_m,-\Im V_m),\quad b_m=(\Im V_m,\Re V_m).
\]

保留 `F=∏ f_m` 后，状态由 Gaussian 核和齐次多项式因子表示，归一化 `Q(X,w)=L_{X,w}[F]`。每次探测直接乘上相应因子，不引入有限弱抽取 ε。相关 Gaussian 条件态与多项式矩方法已有先例，见 [Walschaers 等，PRX Quantum 1,020305](https://doi.org/10.1103/PRXQUANTUM.1.020305)；本轮不把 Gaussian 矩恒等式本身称作新发明。

对于无计数演化参数 `s∈[0,1]`，令

\[
\widetilde X=X(I+sX)^{-1},\quad \widetilde w=(I+sX)^{-1}w.
\]

生存概率为

\[
S(s)=\frac{\exp[-\frac{s}{2}w^T(I+sX)^{-1}w]}{\sqrt{\det(I+sX)}}
\frac{Q(\widetilde X,\widetilde w)}{Q(X,w)}.
\]

条件 Gaussian 核更新为 `X'=(1-s)X̃, w'=√(1-s)w̃`。由于 F 齐次，坐标缩放带来的公共因子在归一化时消去。模式选择使用 `L[F f_m]` 的非负权重；共同归一化不影响选择。

每个二次因子有两个平方项，展开后使用带备忘的 Gaussian Wick 递推计算至多八阶矩。设 `g=L[∇F], H=L[∇²F]`，矩合并为

\[
\delta=Xg/Q,\quad w_{new}=w+\delta,\quad
X_{new}=X+XHX/Q-\delta\delta^T.
\]

保留深度 K=0/1/2/3 分别在第1/2/3/4次光子跳变后执行该合并。合并前的因子被解析保留；合并后仍是近似算法。K 是保留深度，**不是输出光子数上限**。没有光子截断、拒收长轨迹或按结果挑选样本。

根求解继续采用区间保护 Newton 与二分回退；生存导数包含 Gaussian 核导数与多项式矩导数。使用扩展精度矩累加，协方差和谱分解仍为 FP64。谱坐标下统一计算起点归一化，避免两种浮点坐标变换导致 `S(0)` 不一致。

## 独立验证与明确的数值边界

五个固定四模输入、每个六种重复光子因子，使用六点 Gauss–Hermite 的四维张量积分直接计算条件质量、均值和协方差。对不正定 X 使用复平方根和解析多项式积分，阶数足以在实算术下精确积分所有最高十阶多项式；这不是数值误差严格包围。30组检查的最大差约1.98×10⁻¹⁴。另测相干态 Poisson 分布、热态连续光子减法的阶乘矩及 K=0 对旧 Gaussian 重置的逐条回放。

新核心目前有一个明确边界：单模无位移纯压缩输入 `X=diag(-0.25,0.5)`，一次光子减法后的真空概率在数学上为零，FP64 Gaussian 核更新后会得到约 **−4.491×10⁻¹⁶**。K=1/2/3 因而显式终止批次，不裁剪成零、不返回部分记录。K=0会合并掉奇偶信息，在100000样本诊断中出现3800条奇数计数。这项失败没有被混入成功实验；见[原始诊断](../results/iteration73_parity_probe_v1/summary.json)和[带数值明细的复现](../results/iteration73_parity_diagnostic_v1/summary.json)。后续需用保持物理结构的 Gaussian 核或正范数表达解决，而不是静默放宽概率范围。

含损耗、随机位移的两组固定输入另做八个独立200万样本队列（K=0/1/3及旧有限抽取），共1600万条计数。16个单侧界共同分配失败概率0.01。下界事件在此前 pilot 固定，上界为经验完整单纯形 TV 加 Hoeffding 半径和目标尾部；半径 `sqrt(log(1600)/(4,000,000))`。区间依赖理想独立同分布解释和数值目标，不是有限 PRNG、矩舍入或任意输入的全局认证。

## GPU Philox 随机数

新的 CUDA 核使用 `curandStatePhilox4_32_10_t`，每条记录的子序列为 `row_offset+row`。Gaussian 位移使用 `curand_normal2_double`，探测均匀数使用 `1-curand_uniform2_double`，映射到 `[0,1)`。使用双数接口避免单个 Philox `curand_uniform_double` 仅消耗32随机位的问题，参见 [NVIDIA Device API](https://docs.nvidia.com/cuda/curand/group__DEVICE.html)。

点击更新直接包含冻结的第72轮内核，改变的是随机数生成与传输路径。种子映射与旧 CPU 引擎不同，不能声称同种子给出旧记录；导出新随机输入后交给旧 CPU 核可作轨迹核对。分批前后记录一致，输出界限和显存拒绝规则保留。额外随机数组导出用于诊断，性能计时关闭该选项；启用时其成本也纳入时间。

20万条双模热态记录对解析联合点击律的经验 TV 为0.05543%，Gaussian 与均匀数统计检查通过；36,864条四/八模记录的 CPU/GPU 点击逐位一致。随机数网格、统计检查与重放并不构成完整 PRNG 质量证明。

## Frugal AVX2 基线与兼容修复

仍使用固定官方提交 `fa8b796f2afebd4845a2e335e457735952617ef8`。GDB 定位到 AVX2 `vmovapd` 把32字节向量写入仅16字节对齐的栈地址。常规栈重对齐选项未修复；Windows GCC 不支持请求的32字节首选栈边界。LTO 仅使 FP64 的已测 smoke 通过，FP32仍失败。

最终临时构建副本将 NaiveSum/KahanSum 的原有加法函数体移入头文件并强制内联，同时不再编译重复的显式特化源文件。运算顺序和补偿公式不变，官方源文件保持原样，完整差异与失败构建均保留。这是带 ABI 兼容改动的构建，不能描述为源码完全未改。使用 AVX2、关闭 FMA 收缩和 fast math；FP32/FP64 分别为8/4 SIMD通道。

比较接口统一为 C ABI，在同进程返回实际主机点击数组，计入准备、采样及打包，避免将 CPU 进程启动或 JSON 序列化混入主要速度表。GPU Frugal 沿用第72轮已公开的主机布局兼容改动；计算内核未改。四/八模完整参照律与大系统的不同近似质量继续分别报告。
