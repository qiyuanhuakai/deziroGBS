# 第 98 轮：闭环中的光子数与直接点击

把第 97 轮开链的两个端口接在一起，会使多条中间光路产生同一输出。本轮在固定输入族上实现了闭环相干采样。每个单元有四个等强双模压缩源，几何参数为 36/625，信号端通过四阶傅里叶变换。相邻单元的右、左端口用平衡分束器相连，末单元接回首单元。每个单元至多保留七对光子。输出顺序是所有信号端，随后是所有闲置端。[C++ 采样器](../native/gaussian_cycle98_v1.cpp) · [实验参数与七次重复](../results/iteration98_cycle_v1/summary.json)

## 两条路径怎样干涉

给定每个单元的对数、内部两个信号占据及每条边的总光子数，所有相容路径只剩一个整数自由度。若原路径在单元 i 的边界占据为 Lᵢ、Rᵢ，其余路径为 Lᵢ−t、Rᵢ+t，且 −min Rᵢ ≤ t ≤ min Lᵢ。两条不同路径在每条边的输入光子分配上都不同。只要还有一条边未读出，对该边求和就由分束器的幺正性消去交叉项。因此前 C−1 条边可按普通光子转移概率抽取。最后一条边按所有相容路径的振幅交叉项给出条件分布。

PNR 保留闲置端的具体光子数。直接点击只抽取闲置端的点击标记以及本地参与传播的信号占据；共享同一标记的闲置端数态以概率相加。设 Dₜ(k) 为给定路径的实分束器振幅。边上总数大于零时，单侧点击分别使用 k=0 和 k=N 的投影；两侧点击使用单位矩阵减去这两个投影。这样即使两侧均有多光子，也可直接抽取两位点击。相位施加在闭合边的一个输入臂上。[局部傅里叶多项式](../native/fourier_cell98_v1.cpp) · [采样表与独立控制](../experiments/iteration98_cycle_v1.py)

两单元各有一个指定闲置光子、内部信号端均为真空时，平衡分束器在零相位下产生一组概率严格为零的输出。每种方法各抽取 131,072 条，忽略干涉的直接点击、PNR 分别在这些输出上给了 24.804%、24.579% 的频率；加入干涉后两者均为 0 条。此条件分布的理论 TV 差为 25%。另以六个光子、两种具有相同点击标记的闲置占据和 0.674 弧度相位核对，直接点击和 PNR 的样本直方图与独立光学多项式的 TV 分别为 0.396%、1.550%。这两个样本距离包含有限样本涨落。[三个相位的全部概率](../results/iteration98_cycle_v1/controls.json) · [六光子核验](../results/iteration98_release_v1/validation.json)

## 完整分布误差与速度

假设理想均匀随机字。设单元数为 C，单元截断保留率 s 为四个独立几何计数之和不超过七的概率。理想相干计算的截断 TV 至多为 1−sᶜ。未截断网络的信号边界端口具有独立热边缘分布，出现多条相容路径的概率恰为 2pᶜ−p²ᶜ（所有左端非空或所有右端非空）。对有限精度实现，保守地将整个多路径事件都计入可能误差，再加上截断和每次整数抽样表舍入的 TV。在截断成功且单路径的共同样本上，只有抽样表舍入项。此界覆盖完整输出，包括点击粗粒化；短环的界较宽。

| 完整环端口数 | 直接点击，微秒/条 | PNR，微秒/条 | 两条路线的保守完整 TV 上界 |
|---:|---:|---:|---:|
| 16 | 0.0321 | 0.0268 | 0.66246% |
| 128 | 0.0664 | 0.0759 | 0.00002733% |
| 1,152 | 0.3654 | 0.2947 | 0.0002460% |

16 线程，每批 8,192 条，七批中位数，包含完整输出数组分配。共同构表一次耗时 0.247 秒。1,152 端口的结果对应单个长环；若在同样多的端口上布置大量短环，需要逐环处理各自的干涉。固定七对截断时，截断项随单元数增长。[原始计时和逐项误差](../results/iteration98_cycle_v1/summary.json)

**同一 16 端口闭环输入。** 单 CPU 线程、每批 2,048 条，直接点击和 PNR 在构表后各需 0.0364、0.0406 微秒/条。Frugal K2、K4 的完整函数调用分别为 3.61、13.20 微秒/条，约为准备后直接点击的 99、363 倍；仅计 Frugal 内部计时为 3.49、6.26 微秒/条。若一批独自承担本方法全部构表成本，首批约合 121 微秒/条。逐一对照 65,536 个点击词与独立高精度参考，Frugal K2、K4 的完整 TV 分别为 7.150%、1.217%；本方法完整 TV 的保守上界为 0.66246%。[Frugal 实测](../results/iteration98_baselines_v1/summary.json) · [完整参考输入与概率](../results/iteration98_optics_v1/input.npz) · [Frugal 方法](https://arxiv.org/abs/2511.14923)

相同输入的 photonic-engines CPU v2 用时 687.11 微秒/条。在 16,384 条中无截断失败，含 548,591 个低光子数记录和尾部的经验 TV 为 4.882%，按预设抽样方法所得上界为 6.190%。本方法 131,072 条 PNR 样本的同类经验 TV 为 2.544%，样本量不同；上述 0.66246% 为独立的结构上界。固定记录编号从不同批次、不同线程数采样，两条路线均逐字节复现。[PNR 参考、样本核验与首批大小计时](../results/iteration98_release_v1/validation.json) · [基线记录](../results/iteration98_baselines_v1/pe.npz)

## 到九章数据的差距

九章 3.0 论文给出的硬件速率约为 1.27 微秒/条，使用多路阈值探测器进行准光子数分辨。上表的闭环速度来自另一个光学输入。把这套无损成对模型直接用于九章有损双谱光学输入，会出现可量化的障碍：它生成奇数总光子数的概率恒为零；有损参考的相同概率约为 50.000%，因此仅此事件就使完整 PNR TV 至少约 50%。按总数生成函数在 −1 处求值，与逐项累加至 1,024 光子的结果一致，余下质量低于 1.04 × 10⁻⁵¹。此项比较使用光学参考；九章硬件的点击总数是另一种观测量。在同一硬件数据上，第 97 轮位移场的直接点击和 PNR 转点击总数 CDF 仍分别相差 4.233、4.338 个百分点。下一步可在闭环模式上加入独立损失通道，用奇偶概率和完整点击分布共同检验。[奇数事件核验](../results/iteration98_release_v1/validation.json) · [真实点击直方图对照](../results/iteration97_field_v1/summary.json) · [九章 3.0 实验](https://arxiv.org/abs/2304.12240)

## 复现

在固定归档的 Windows 工作目录中，以下命令分别生成完整点击记录与 PNR 记录。随机数以实验、用途及记录编号分域；同一输入和种子可用 `--offset` 分批复现。[命令行入口](../experiments/iteration98_sample_ring_v1.py)

```sh
python experiments/iteration98_sample_ring_v1.py clicks.npz --cells 144 --route click --shots 8192 --seed 98009000 --workers 16
python experiments/iteration98_sample_ring_v1.py photons.npz --cells 2 --route pnr --phase 1.57 --seed 98009001
```

完整重跑按下列顺序使用新的输出目录。核验程序默认读取归档内命名的基线与参考文件；如要逐项复算，可在独立工作目录中使用源码中列出的规范目录名。上游 photonic-engines 版本记录在基线计划中。[版本和输入哈希](../results/iteration98_baselines_v1/plan.json)

```sh
python experiments/iteration98_cycle_v1.py ring-rerun
python experiments/iteration98_optics_v1.py optics-rerun
python experiments/iteration97_bridge_baselines_v1.py baseline-rerun --input optics-rerun/input.npz --seed 98120000
python experiments/verify_iteration98_v1.py validation-rerun
```
