# 第67轮冻结计划：相同误差下的匹配链成本

正式执行前固定。triangle3、path4、cycle4来自12项探索预检，star4和diamond4是两个新图留出。所有图均固定c=1/4；原图条件目标对应B=c²A的有效纯Gaussian输入，但只研究无碰撞条件分布，不宣称完整无条件GBS采样。

每图α∈{1,4,16,4n²}，共20个理想核；精确拒绝随机字实现保持这些核。时间网格固定16、32、64、128、256、512、1024步，共140个有限律。分别在TV≤1/100和≤1/1000时，按“期望随机字数、期望转移步数、α、步数”依次排序选择候选，并与固定α=4n²在同网格内的最佳合格候选对照。若没有合格候选，保留不可行结果，不扩大网格或换图。

每次尝试从空态固定运行t步，完美时返回其原图投影，否则独立重启。不使用首次命中停止。本轮采用无次数截断的重启：若单次成功质量p>0，则独立随机字模型下几乎必然终止，期望转移数t/p。没有确定性运行时上限，也不把这个结论外推为有限种子PRNG的全周期保证。

随机字成本也要精确核算。均匀[0,b)拒绝取模的期望字数为2^64/(2^64−2^64 mod b)，b=1时为0。每状态一步成本包括懒惰判断、非懒惰时的选边及必要的有理Bernoulli。生产端对前向状态分布累积奖励；独立端用反向价值递推重建每个固定步尝试的期望字数C。重启后的总期望为C/p，即使单次成本与成功事件相关也成立，因为下一次尝试独立。

完整状态和核由顶点递归与边组合两种算法复建；图目标从独立原图匹配组合复建。独立验证精确物理界、平稳律、详细平衡、全部有限律、成功质量、条件TV、奖励递推和成本。选择在这些证据通过后才执行。公开轨迹每个图/误差/可行路线7个输出，最多140个；保留每次失败尝试、全部状态和64位字。独立集合算法逐步重放，并设置强制拒绝尾部的确定性控制。

只比较冻结有限候选集合内的精确期望资源，不宣称连续参数全局最优、墙钟速度或大图混合定理。所有科学源码首次执行前快照；预检、失败、不可行和正式结果分别保留。第66轮发布后更新发布基线，再执行覆盖全部新文件的全库测试。重大进展与原始先进工具及九章对照，持续目标保持进行中。
