# 第36轮进展与先进工具、九章的对照

核查日期2026-11-09。第35轮已保存[完整前沿表](iteration35_frontier_comparison.md)。本轮进一步核对FrugalGBS作者稿、11月有损采样预印本及九章来源；九章团队网页本次访问暂不可用，数值沿用第35轮同日已读取的团队原文，并明确这一访问限制。本轮没有重新运行外部工具的同机同输入性能面板。

| 对照 | 本轮新增证据如何改变判断 | 尚不能声称 |
|---|---|---|
| 本项目森林代理 | 前八步可有很小的确定性TV区间，同时部分配置的完整144位输出已被预声明点击尾事件检出明显偏差。以后须优先核查长历史近似，不能把早期前缀当全局质量。 | 预算更大或统计下界更小就一定有更低的真实TV；未检出配置已准确。 |
| [FrugalGBS](https://arxiv.org/abs/2511.14923) | 该论文报告百模既定基准上的单CPU/GPU表现。本轮的认证目标区间及完整输出事件方法可用于同目标测试，而本项目森林偏差不自动归因于Frugal的累积量近似。 | 本轮已战胜或否定Frugal；既有固定版本集成等于本轮公平重测。 |
| [低纠缠MPS方法](https://arxiv.org/abs/2512.10643) | 有效B,F模型和直接局部真值可改进张量网络误差账本。应以同一目标比较Fock/MPS截断和同噪声通道后的完整输出统计。 | 本轮运行过新的MPS对照，或局部MPS界证明完整大系统准确。 |
| [The Walrus](https://hafnian.readthedocs.io/en/stable/gbs_sampling.html)、[Piquasso](https://piquasso.readthedocs.io/en/stable/tutorials/gaussian-boson-sampling.html) | 成熟数值工具仍是可完整审核的小系统参考。本轮增加的是精确目标区间与观测量证书，不是另一个通用高速精确采样器。 | 未经同输入测时的速度优势，或这些软件全部计算都没有自身的校验机制。 |
| [Angrisani–Mhiri最新预印本](https://arxiv.org/abs/2611.08444)及[Lim固定损耗工作](https://arxiv.org/abs/2611.01434) | 等压缩、损耗与Haar平均/高概率等前提仍须逐项检查；具体森林算法失败不反驳适用族中的存在性或构造性可模拟定理。 | 当前非均匀B,F模型自动符合所有理论前提；多项式渐近保证已经转换为有限资源实现。 |
| [九章4.0团队原文](https://quantum.ustc.edu.cn/en/node/1227)、[Nature论文](https://doi.org/10.1038/s41586-026-10523-6) | 团队报告1024压缩输入、8176模式、最多3050探测事件及25.6微秒每样本。我们仍只研究144模数学目标，且部分完整采样代理被检出失真。二者模型、探测设置、误差与资源均未对齐。 | 用本轮耗时或样本成功数计算“比九章快/慢多少”；本轮已模拟九章，或森林失真证明所有经典方法都失败。 |

本轮是两方面的重要进展：把精确物理模型的局部真值算得更紧，并建立能否定部分完整代理准确性的证据。它不提供完整分布上界，也没有新的量子优势胜负结论。下一次真正的算法质量改善必须使用预先冻结的独立确认数据，并同时给出确定性区间、统计假设、失败规则与资源口径。[后续计划](iteration37_plan.md)。
