## 2. 每条样本自己的 log Q

打开 `--record-log-probabilities` 后，返回 `sample_log_probabilities` 数组。第 t 项对应同一位置的原始样本，定义为

\[
\log Q(x)=\sum_j\left[x_j\log p_j+(1-x_j)\log(1-p_j)\right],
\]

其中 p_j 就是当时用于比较 `uniform < p_one` 的条件概率。记录发生在实际抽样循环中，不重新拟合概率，不访问物理目标 P，也不进行丢弃、重抽或后选择。

实现用 long double 累加，点击分支调用 `log(p_one)`，零分支调用 `log1p(-p_one)`，最后以 double 输出。合法确定性分支贡献 0；若实际选中了零概率分支或出现非有限/正的 log 概率，程序明确报错。日志数组、随机数引擎、样本存储的分配与日志计算都计入 sampling 时间。

该值表示**程序计算出的条件链在理想连续均匀随机数下的概率**，不是有限 PRNG 所有状态的精确枚举，也不是物理目标 P(x)。它使外部验证器可以把样本与其 Q(x) 配对，却本身不能证明 Q 接近 GBS。

返回元数据包括 `log_probability_enabled`、`sample_log_probability_semantics`、`sample_log_probability_accumulation` 和日志数组字节数。关闭功能时数组为 null；零样本且功能开启时数组为空。

## 3. 小矩阵核：乘积与对数公式

原核对 H=(W_S+I)/2 作 Cholesky 分解 H=LLᵀ，再计算

\[
v(S)=\exp\left(-\sum_i\log L_{ii}\right).
\]

新 `product` 选择在相同的 double Cholesky 因子上计算

\[
v(S)=\frac{1}{\prod_i L_{ii}}.
\]

它去掉了常见路径上的逐对角 log 与一次 exp。若中间乘积不是 normal 浮点数，程序使用原对数公式重新计算；行列式因子本身仍必须正且有限。这个回退防止把乘积溢出、下溢或精度恶化直接转换为概率结果，没有引入新的概率截断。

采样、选集与 pairwise 初始化的诊断分别记录：

- `vacuum_product_evaluations`：成功的乘积快路径次数。
- `vacuum_product_fallbacks`：乘积路径触发对数回退的次数。
- `vacuum_log_evaluations`：实际采用对数公式的次数，包括回退。

所有 Gaussian 零更新、选集规则、容斥累加及保护门槛保持原样。两种核在同一可执行文件中选择，便于把实现差异与编译条件分开。

## 4. 已完成的核验

运行器、输入、均匀数、完整 Q、样本、结果和源码快照均保存在 `results/iteration4_kernel_validation/`。数据绑定二进制、源码和输入散列；这里没有用数值检查的运行时间作性能结论。

### 4.1 固定小规模输入

使用第三轮的 27 个 10/12 模式输入、两个选择器、k=4，共 **54 个配对比较**。每个比较使用同一组 32 条注入均匀数，测试新 log 核、新 product 核、关闭日志的新 log 核和冻结 v3 样本；两个新核都枚举完整 Q。

| 检查 | 结果 |
|---|---|
| 新 log 核与 v3 的完整 Q | 54/54 逐位相同，最大 TV=0 |
| 新 log 核与 v3 的同均匀数样本 | 54/54 相同 |
| 日志开关对同均匀数样本的影响 | 54/54 无变化 |
| product 与 log 的完整 Q | 54/54 通过原 2e-8 门槛；最大 TV=9.381890334359396e-14 |
| product 与 log 的同均匀数样本 | 54/54 相同 |
| logQ 与完整 Q 对应点的对数 | 最大绝对误差 1.7763568394002505e-15 |

这里的“相同”是该固定集合上的结果，不是任意输入与任意编译器的逐位保证。尤其是贪心选集可能放大近乎并列分数的舍入差异，不能把未测试输入自动视作通过。

### 4.2 数值保护、支持和范围回退

六个原有严格支持/弱热态压力例，在两个核下均继续明确报错：四个双模对例完成 64 个样本后，在另行进行的完整 Q 枚举中触发保护；两个弱事件例在第一条样本中触发保护。保护相位与完成样本数未改变。这些例子不是完整分布成功求值。

另行关闭枚举，重放四个双模对批次、两个核，共八个批次：全部与冻结 v3 的同均匀数样本相同，没有禁止支持模式，logQ 对解析概率的最大绝对误差为 4.440892098500626e-15。

附加的 65 模式真空例检查跨 64 位边界、反序测量、确定性零分支和 logQ=0。2 模式高温热态例 V=10²⁰⁰I 则确实触发 product 的范围回退；两个核都正确给出其浮点条件链的确定性样本与 logQ=0。该极端例只用于回退路径，不能用来声明高精度的极端物理概率。

### 4.3 144 模式的解析密度检查

非相同独立热态取 n̄ 从 0.2 到 0.6 变化，使用反序测量与 8 条固定均匀数。解析阈值点击概率为 p_j=n̄_j/(1+n̄_j)。两个选择器、两个核共四次检查全部通过：样本与解析独立 Bernoulli 规则相同，logQ 与解析乘积概率的最大绝对差为 **4.223649208157099e-12**。

独立热态是经典易解例子。它验证大模式坐标和密度记录，不验证一般高点击 GBS，更不代表模拟了九章。

## 5. 跨模式优化的实际边界

把小矩阵核变快不会移除当前全局状态表示的增长：

- 单个实协方差矩阵有 (2m)² 个 double，占约 **32m² 字节**。
- 每个零观测需要更新剩余稠密协方差，单次为 O(m²)；最坏情况下每条样本的全部零更新为 **O(m³)**。
- 输入物理性检查还使用完整复 Hermitian 特征值求解，其设置成本随规模立方增长，并需要额外矩阵内存。
- 选择器保留全部历史点击模式，k 只限制本次施加的点击约束，不把全局状态缩成 k 个模式。

因此“跨模式优化”应包括模式数、点击数、损耗、全局状态成本与误差的联合测量。当前 256 上限是明确的实现边界，不能通过只改一个常量就声称已覆盖数千模式。

对更大系统，可能需要结构化协方差、按需块查询、更新表示、低秩或网络结构等新的状态组织方式；这些都需要单独的误差与复杂度论证，本轮尚未实现。主报告的跨模式剖析将决定下一处优化应该落在事件核还是全局状态更新。
