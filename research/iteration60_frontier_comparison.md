# 第60轮：先进工具与九章对照

2026-11-10重新核对四篇原始arXiv版本页及官方Frugal HEAD，元数据保存在results/iteration60_frontier/verification.json。随后扩展检索并复核检测重置及相位扩散来源，增补记录在additional_sources.json，不覆盖首次记录。此为已核查路线对照，不声称穷尽所有最新工作。

| 路线 | 原始来源 | 本轮能够支持的比较 |
|---|---|---|
| Frugal | [Dodd等v1](https://arxiv.org/abs/2511.14923)，[官方仓库](https://github.com/tomdodd4598/FrugalGBS)，HEAD fa8b796f2afebd4845a2e335e457735952617ef8 | 本轮在另一条位移路线的小系统中比较不同误差预算，没有新运行Frugal，也没有同一目标、同一误差的速度对照。第56—57轮144模的既有下界与极弱上界维持原范围。 |
| Gaussian-SVD / PCO | [Liu等v2，2026-05-11](https://arxiv.org/abs/2512.10643) | 论文构造适用于有限纠缠纯Gaussian态；本轮常规全Fock箱SVD仍不是其算法。复相位族扩大有限箱更有效，说明应继续研究输入近似预算，但尚未运行或验证作者官方构造。 |
| 热损耗理论 | [Angrisani与Mhiri v1，2026-11-05](https://arxiv.org/abs/2611.08444) | 固定均匀压缩、固定非零损耗、Haar高概率等条件需分别核对；平坦性假设下另有准多项式结论。三固定两模输入的预算结果不能证明任意大系统高效可模拟。 |
| 检测后Gaussian重置 | [Lim v1，2026-10-05，定理2与补充SV](https://arxiv.org/html/2610.06526) | 主定理在规定的固定压缩、均匀损耗PNR设置下给出min(1,C₃(r)Nη³)界；文中明确不将该定理用于位移噪声变体。延续[第23轮常数审计](iteration23_literature_update.md)，不能把阶数符号移植成本项目数值证书。 |
| 相位扩散与Heisenberg张量网络 | [Cilluffo等v1，2026-08-31](https://arxiv.org/abs/2608.31089) | 研究碰撞自由GBS的干涉分解及相位扩散。当前Gaussian位移噪声与该噪声模型不同；阈值聚合输出也不等于碰撞自由PNR事件。本轮没有复现其算法或推断其复杂度。 |
| 九章4.0 | [Liu等v3，2025-08-24](https://arxiv.org/abs/2508.09092) | 论文报告1024压缩输入、8176模、最高3050探测事件及25.6微秒/样本。本轮15552个位移节点不是物理模式数，两类投入也不是等成本。因此没有九章规模或同质量速度结论；论文指定MPS构造估算不是通用经典下界。 |

本轮推进的是“误差来源能否帮助选择下一笔计算预算”：已明确冻结选轴规则并执行后续完整程序。实际误差改善不代表一般输入的最优方向，更不等于硬件或外部工具速度优势。下一轮优先回到实际144模次序与前缀证据，同时保留小系统联合预算和MPS构造路线。
