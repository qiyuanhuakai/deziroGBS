# 第61轮方法：固定物理集合内的排序对照

## 目标、变换和可比性

实验输入是第35轮既有144模物理模型的shifted浮点协方差，原物理目标由B、F确定。只置换前16个模式，其余128模原序不动。排列π使用“采样位置j对应物理标签π(j)”约定；q/p两块都按π排列，R=diag(P,P)。生产使用索引抽取，验证用独立逐元素双循环重建全矩阵，CSV以17位有效数字往返。

精确物理协方差作相同置换时，真空子集概率满足p′vac(S)=pvac(π(S))，因为对应主子矩阵仅经过相同行列置换，行列式不变。阈值原子的容斥表达于是只重标记。对任意采样位置位串x，物理位串y满足yπ(j)=xj。本轮不重新生成物理证书：绑定第56轮已独立审核的65535个子集证书所得16位目标及验证记录，第37轮start=0十模目标用于对照。全部标签双射在新审核中逐原子复核。

同一酉模式置换保持迹距离，故原目标转移界不变。表格主要TV相对原物理目标；对shifted目标的整体TV下界是max(0,L−δ)。浮点预处理可能产生排序相关舍入，本轮结果是固定实际实现的结果，不将它们全部归因于截断。

## 执行和随机模型

沿用第42轮冻结frugal_prefix.exe及其DLL，K1—K4原生算法不变。主要新实验为reverse与even_odd两种次序，每种四阶，共8项。前缀深度16，每项17公开样本、seed391440。原序K1重跑与第56轮严格比较；另有十模三种次序、K1和K4的6项控制。全部15项执行前已冻结在[计划](iteration61_order_plan.md)。

独立均匀uint64随机字经GCC所核查的binary64转换和端点截断，导出每个阈值对应的精确零分支概率。整棵前缀树给出完整16位边缘，而非对17个公开样本做统计估计。另保留连续均匀随机模型，并核验两者耦合界。固定种子仅用于公开路径回放，未认证PRNG全周期分布。

生产用full_law，验证用另一套layer_law及uint64转换二分搜索。每个节点复核阈值商、父子概率连续性，每个公开路径复核随机字决策；新实验和四个旧原序基线均重新构造程序律。两种重建均使用导出的原生浮点阈值，不声称另行证明原生累积量公式等于精确量子条件概率。

## 距离区间、顺序差异及混合

目标原子Pi位于[ai,bi]，精确程序概率为qi。使用L=½Σmax(0,ai−qi,qi−bi)，U=½Σmax(|qi−ai|,|qi−bi|)。若新U小于旧L，判定严格改善；若新L大于旧U，判定严格退化；否则保留未决。目标区间误差与二进制舍入造成的程序差异分别记录，即使变化很小也不以浮点打印相等代替精确相等。

所有顺序映回相同标签后计算程序间TV。预声明的混合是Qmix=(Qidentity+Qreverse+Qeven_odd)/3，独立于结果选择权重；其TV由完整律计算，并核验凸性上界。这里是理想精确1/3选择的数学分布，没有新增有限随机字混合入口、预处理复用实现或匹配质量速度结论。

144模边缘TV区间只为完整144模TV提供下界。边缘更小、排序更好或混合改善，均不证明整体144模TV更小。十模对照则覆盖该十模模型全部输出。输入均是既有模型，没有新物理留出。

## 复现

在仓库根目录设置PYTHONPATH=src，依次执行：

```text
python experiments/iteration61_order.py
python experiments/verify_iteration61_order.py
python experiments/iteration61_analysis.py
python experiments/iteration61_tests.py
python experiments/iteration61_seal.py create
```

所有输出目录要求不存在，防止覆盖冻结证据。原始标准输出和精确分数律保存为确定性gzip，存储记录附原始字节长度及SHA-256。全库测试与主要验证完成、图表人工检查后才封存清单；源码快照与Git提交字节分别核对。已存在结果需在独立目录/检出中复现。
