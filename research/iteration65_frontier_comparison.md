# 第65轮：联合噪声预算与先进工具、九章对照

2026-11-10。本轮直接复核Gaussian-SVD/PCO、Goodman等计数基准、热损耗理论和九章4.0原始论文；其他路线沿用同日既有来源。Goodman工作已在第35、37轮讨论，本次是针对噪声预算的复核，不计为新发现。

| 路线 | 原始来源 | 本轮关系与适用边界 |
|---|---|---|
| Gaussian-SVD / PCO | [论文v2](https://arxiv.org/html/2512.10643v2)、[作者代码与数据](https://zenodo.org/records/18045305) | 式38及附录C要求混合协方差减去纯态协方差为半正定。本轮从有效纯态及显式四驱动构造噪声，并独立检查协方差，未新运行作者PCO。有限Fock箱的普通SVD不能算作Gaussian-SVD。第22轮144张量参考重建已经完成；第27轮指定数据的PSD失败仍保留，不能裁掉负特征值后称为原目标。 |
| 大规模计数基准 | [Goodman等](https://arxiv.org/abs/2604.12330) | 作者报告最高1152模输出计数基准表现超过对应实验。本轮审核两模完整阈值分布与程序失败事件，指标和规模不同；未复现该工具，不将作者性能陈述变成独立排名或完整TV保证。 |
| 固定热损耗 | [Angrisani–Mhiri](https://arxiv.org/abs/2611.08444) | GBS结论保留固定统一压缩、Haar干涉仪高概率等前提；无Haar时另有平坦性条件。本轮是指定小输入的完整有限程序证书，不证明这些理论对144模或九章指定线路成立。 |
| 固定损耗与Frugal | [Lim](https://arxiv.org/abs/2611.01434)、[Frugal](https://arxiv.org/abs/2511.14923) | 沿用此前原始来源审核及144模实验。本轮没有新增对应运行、整体144模TV证书或等质量吞吐比较。Lim的位复杂度讨论不能忽略，平均结论也不能自动变成指定输入证书。 |
| 特殊图与局部链 | [Anand等](https://arxiv.org/html/2511.16558v3)、[Chen等定理12](https://arxiv.org/html/2504.02740v1) | 第63—64轮已有目标投影、实际链、有限字和停止律结果。噪声预算与链的步数预算是不同问题；本轮不把联合噪声结果计作大图混合保证。 |
| 九章4.0 | [原论文v3](https://arxiv.org/html/2508.09092v3)、[Nature论文](https://www.nature.com/articles/s41586-026-10523-6) | 作者报告1024压缩输入、8176模式、最高3050探测事件及25.6微秒/样本。本轮仅两个物理模式、四个实驱动；四驱动满秩不等于四物理模式。没有九章规模模拟或同质量速度优势。论文对指定MPS构造的外推时间不作为所有经典算法的下界。 |

[第28轮](../RESEARCH_REPORT_ITERATION28.md)已经构造了明确的144模邻近Gaussian模型及噪声因子；[第29—30轮](../RESEARCH_REPORT_ITERATION30.md)也已有同噪声通道的有限MPS输出与实际采样。这里所说的未闭合，特指原始指定输入、Gaussian-SVD局部核、实际有限张量及完整误差证书之间的绑定，不是否认这些已有结果。

本轮新增的是执行前固定的物理留出与完整四方案比较：有限输入维数、噪声网格及两者联合投入都有实际完整概率律和独立上界。比较保留不同成本、仅五个输入以及未执行其他候选轴完整程序的限制，不能据此宣称普遍最优的资源分配规则。
