# 第38轮及持续方向

第37轮确认面板的事件族冻结不变。以下新诊断仅供后续冻结方案使用；不能在看过第37轮结果后把它追认为本轮预声明检验。

## 优先补强全局诊断

目前用目标均值/方差推出的Cantelli尾上界可能太宽。增加样本不一定消除这一瓶颈：如果代理尾概率也低于这个宽松上界，原检验会一直未检出。

可先研究一个简单的非负乘积见证。令N为完整输出的点击模式数，定义X=N/144，失败输出预先定义X=0，故0≤X≤1。假设n次尝试独立同分布，代理均值为μ_Q，则E[∏X_i]=μ_Q^n。由Markov不等式，

    L = (α ∏X_i)^(1/n)

满足Pr(L>μ_Q)≤α。若出现X_i=0，直接取L=0。它不假设代理方差已知，也不把有限样本方差当作确定常数。可用精确有理乘积和向下有理开根得到可审查下限。相同方法对1−X给上侧均值约束；多个配置和两个方向仍须分配联合错误预算。

对目标P，已认证的E_P X区间为第36轮均值区间除以144。因任意[0,1]值函数的期望差至多TV，max(0,L−上界(E_P X))是完整扩展输出TV的有效单侧统计下界。该论证只是标准独立乘积与Markov见证的直接应用，不主张统计方法创新。

这里P仍是精确B,F目标；若改报相对实际加噪协方差目标的质量，下界再减去第35轮已认证的目标转移上界并截于零。Bernoulli零/一变量给出可接近Markov界的覆盖率边界控制，常数变量、全零样本和带失败样本也应纳入测试。

实际功效仍未知：乘积受几何均值与零结果影响，小样本置信修正也明显。先用已完成轮次作训练/功效评估，验证边界和覆盖率，再冻结新样本数、辅助变换、事件族、α分配与随机流。可进一步研究固定或可预测下注的均值见证，但必须证明覆盖率，不能使用事后选择的下注参数而遗漏修正。

已有样本上的探索计算：取α=0.01/8，第36轮四组的L−目标均值上界依次约0.09502、0.04855、0.04441、0.01219。第四组原尾检验未检出，这提示新见证值得做独立确认；这些数值来自事后训练分析，不是新增的预声明99%结论，也不与原轮次错误预算混合。

另一个确定性小改进是利用点击数整数支撑。对整数a≤K−2，

    1[N≥K] ≤ (N−a)(N−a−1) / ((K−a)(K−a−1))

对N∈{0,…,144}成立：相邻整数根之间没有可取整数，且N≥K时多项式单调不小于分母。用认证一、二阶矩计算其期望，枚举事先规定的a并与Markov/Cantelli取较小值，可得到无需新矩证书的尾上界。改进幅度需实算，不预先称其解决检验功效问题。

以当前目标矩作代数试算，K=80时上界由约0.320484降至0.320089（a=60）；K=90时由0.131960降至0.131679（a=63）。幅度很小，因此这条支线有助于收紧证书，但预计不能单独解决当前检验的功效瓶颈。第37轮已冻结的检验仍使用原上界。

## 其它方向

1. 在第37轮同一物理目标上恢复固定版本官方FrugalGBS基线。先用三个十模式边缘做完整实现律比较，分别注明“独立十模式输入算法”与“完整144模式算法的停止律”，两者不可默认相同。原适配器只编译2至16模式；完整144模式基线需要另行扩展和校准，不能把小系统接口当作已有大系统能力。
2. 对条件互信息的反例分析选择集合变化与遗漏图。若试验零条件化树或分支条件化图，先隔离图变化和保留规则变化，再冻结新确认；保留当前静态树作固定对照。第37轮另有[精确二元小例子](iteration37_tree_objective.md)表明联合KL最优树未必使全点击后验最准确；须进一步研究Gaussian可实现性，不能直接把一般二元反例当作本项目物理结果。
3. MPS继续对齐B身份、Fock截断、秩截断与相同位移通道。第32轮有限MPS局部见证和第35轮精确B,F目标之间的接续要逐项说明；不能只换目标标签就宣称外部同任务比较完成。
4. 继续探索可控制剩余输出质量的确定性分解。十模式完整律即使很准确，仍不能给高点击144模式完整TV上界。
5. 保持来源哈希、实际失败、独立核验和普通快进发布；重大进展继续重新检索先进工具与九章，清楚区分文献宣称、本项目实测及尚未复现部分。
