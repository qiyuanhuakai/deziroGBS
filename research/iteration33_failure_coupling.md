# 有限分布的失败感知耦合与未审核质量

## 对象和范围

目标P是恰好归一化的m位离散表。算法在历史h返回点击条件q(h)，或明确失败；失败立即终止并输出同一符号⊥。于是Q是成功串与⊥上的归一化分布，P(⊥)=0。本轮审核器使用Fraction，给定表上的关系没有浮点容差；Gaussian目标表生成误差并未因此消失。

第32轮复用的浮点目标表先逐项转换成确切二进制有理数，再显式除以原总质量S，保存S和改变量。最大的|S−1|为1.734723475976807e−17，归一化L1改变量也为该值。这只是归一化误差，**不是相对于真实Gaussian概率律的总误差界**。若未来独立获得TV(P真实,P表)≤ε，才能用三角不等式把当前上界增加ε后转移。解析热态控制没有这个目标表问题：给定精确v的独立点击率为(v−1)/(v+1)。

## 保持相同历史的质量

记p(h)=P(next=1|h)，c(h)为逐步最大耦合下尚未分歧并到达共同历史h的质量，c(空)=1。在成功节点，令δ(h)=|p(h)−q(h)|，则

    d(h) = c(h) δ(h)
    c(h0) = c(h) min(1−p(h), 1−q(h))
    c(h1) = c(h) min(p(h), q(h)).

在失败节点，把c(h)全部记为分歧，另以Q(h)记入实际失败概率；二者不能混用。P(h)=0时取p(h)=q(h)，不改变P；Q(h)=0的未访问历史可将q扩展为p，不改变Q。原生Oracle中的其它程序异常向上抛出，只有显式None代表数值失败。

完整访问后，分歧质量D=Σ_h d(h)=1−Σ_x c(x)。耦合不等式给出

    Q(⊥) ≤ TV(P,Q) ≤ D ≤ min(1, H_P, H_Q),
    TV(P,Q) = [Σ_x |P(x)−Q(x)| + Q(⊥)] / 2,
    H_P = Σ_h P(h) δ*(h), H_Q = Σ_h Q(h) δ*(h),

其中失败节点的δ*=1，其余为δ。最后一步由c(h)≤P(h),Q(h)逐节点推出。H_P/H_Q是已有条件混合界的失败扩展；[已有推导](phase2_theory.md)已包含普通求和界，本轮不主张算法或理论首创。D一般不是最优的全局耦合，可能明显大于实际TV。

## 提前停止不能忽略剩余树

维护尚未查询的前沿F。已知分歧为D_seen，已完成共同叶质量为C_leaf，剩余共同质量为U=Σ_{h∈F}c(h)，恰好满足

    D_seen + C_leaf + U = 1.

把未审核部分全部按最坏情况记账，就有全程TV≤D_seen+U=1−C_leaf。成功节点展开只在到达叶时减少这个最坏情况界，失败节点把原本的未控共同质量转成已知损失，并不会凭空降低它。另独立核对已完成成功串质量+已见失败质量+剩余Q前沿质量=1。部分审核时不输出“精确TV”或“完整混合界”。

实现每次查询c(h)最大的前沿节点，并用历史字典序破同值。这个启发式没有最优查询复杂度保证。对24个八模式冻结森林表，8和32次查询后的界均为1；128次后仍为0.4930…0.6721；全部255次后才显著变小。对于集中在真空附近的热态，少数叶已覆盖较大质量，界可以更快收紧。这是面板现象，不是对所有审核方法的复杂性下界。

目标前缀仍由完整2^m表计算，限制m≤14，成本约O(m2^m)，并有随路径增大的有理数算术开销。因此本轮是可审核的小系统基准工具，尚未提供144模式的可扩展认证器。八模式森林仍只是在第八步停止的分布，未来失败不能从这个前缀结果推断。

## 抽象有限网格

若每次U独立均匀取自{0,1/2^b,…,(2^b−1)/2^b}，并以严格U<q生成点击，则有效点击率为

    q_grid = ceil(2^b q) / 2^b.

q=0和q=1均保持不变；正概率小于一个网格单位时变为2^-b。本轮穷举小网格验证公式，并用b=53逐节点重新构建完整分布，包括失败概率。两种全程法则的TV≤m/2^53由每步偏移与耦合界得到；独立审核以有理数检查。本面板实际最大偏移4.380648349477888e−16。

这只是明确的随机网格模型，不是特定PRNG跨调用独立性的证明，也没有修改采样器。原生event计算、最终binary64条件值、理想Bernoulli抽样和有限随机数网格是不同误差来源。b=8热态的quad/auto理想误差约10^-18，网格误差约10^-16，不能直接把前者称为真实实现的端到端误差。

## 独立审核与状态范围

主程序按共同质量优先遍历；审核器不导入主函数，而用深度优先递归枚举法则，并从共同叶乘积算1−C_leaf。两种实现核对全部记录、每层损失、两种混合界、失败、完整/部分守恒及确定的访问优先级。原生14项工作在新实例另以深度优先查询，条件二进制值和失败支持逐项相同；这只覆盖实际核对的两种顺序，不证明任意缓存状态下都相同。

所有失败概率都来自完整有限树而非蒙特卡洛估计。不丢弃失败，不对成功条件化，不重新抽样。NumericalProbabilityError的消息保存在每个失败节点，端点拒绝和保护门槛维持原语义。
